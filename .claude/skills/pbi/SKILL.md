# PBI

Two separate jobs — read **only** the file for the job at hand:

| The dev wants to… | Read |
|---|---|
| Capture an idea, bug or task as a new PBI | `create.md` |
| Update an existing PBI: move its card, tick finished boxes, add a short "what was done" note | `update.md` |

If it's unclear which one, ask. Review levels (`L1`–`L4`) for both are defined in `review-levels.md`.
