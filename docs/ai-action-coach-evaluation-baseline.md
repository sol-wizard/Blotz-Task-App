## 人工查看发现的语义问题

客观断言通过不表示这些质量问题通过。原始 JSONL 的 `semanticStatus` 统一保持 `needs_review`；本节记录本轮人工查看的发现，不充当完整校准后的评分。

| 场景 | 观察 | 判断 |
| --- | --- | --- |
| listen-Clarify | 用户明确不建议，回复仍说“你今天可以先把所有节奏都放慢一点，允许自己什么都不做” | 未完全遵守用户限制 |
| listen-Companion | 回复含“那就好好放空吧” | 存在轻微建议性表达，需按产品口径复核 |
| defaults-Execution | 用户委托决定时间，回复直接给 19:00–20:00，虽说可修改，但没有明确说明时间由 AI 暂定 | 暂定时间表述不足 |
| invitation-Companion | 第一轮用户说先不创建，回复仍附“如果你之后想，我可以再帮你……任务草稿” | 推迟建卡后仍附邀请，应检查是否违反等待用户重新表达兴趣的规则 |
| recurring-Execution | 日程结果为 partial，回复没有说明仅检查初始窗口 | 未声称整个周期空闲，但检查范围的表达值得加强 |

冲突场景保留用户指定时间并说明会议冲突；自然语言改期、App 改标题、模型再次改时间及正式保存重放的客观检查通过。没有据此给出“全部质量达标”或发布 GO 结论。
